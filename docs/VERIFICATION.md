# Phase 0 인수 검증 체크리스트

Phase 0(PC 유선 연결 3DoF 프로토타입)이 완료되었다고 판단하기 위한 기준입니다. 모든 항목을 통과해야 Phase 1로 넘어갑니다.

## 1. 기구 (Mechanical)

- [ ] 3D 프린트한 셸이 오류 없이 출력되고, 모든 부품(패널, 렌즈, 드라이버 보드, IMU)이 조립된다
- [ ] 렌즈와 패널 사이 거리(lens-to-panel distance)를 조절할 수 있다 (최소 범위 ±5mm 이상, 수치 기록)
- [ ] 조절 후 나사 또는 고정 장치로 위치가 고정된다
- [ ] 두 렌즈 중심 간격이 IPD 63mm로 맞춰지고, 실측값을 기록한다
- [ ] 셸 조립 후 얼굴에 착용할 때 코 부분 절개(nose cutout)가 걸리지 않는다

## 2. 무게

- [ ] 헤드셋 전체 무게가 **350g 이하**이다 (배터리와 케이블 포함, 실측값 기록)
  - 측정값: ______ g

## 3. 센서 (IMU)

- [ ] IMU가 Linux에서 인식되고 `firmware/imu/read_imu.py`의 `serial` 또는 드라이버 백엔드로 데이터를 읽을 수 있다
- [ ] IMU 출력 주기가 **500Hz 이상**이다 (측정 명령: `python3 firmware/imu/read_imu.py --backend serial --port <장치> --seconds 10 --expect-hz 500`)
  - 측정값: ______ Hz
- [ ] 정지 상태에서 쿼터니언 드리프트가 1분 동안 합리적인 범위(예: 5도 이내)에 있다

## 4. 지연 (Latency)

- [ ] 머리 방향 지연(head-orientation latency)을 측정했다 (고속 카메라 또는 LED 타이밍 방식)
  - 측정 방법: ______________________
  - 측정값: ______ ms (목표: 가능한 낮게, 기록 우선)

## 5. 비용

- [ ] Phase 0 총 비용이 **$120 이하**이다 (실제 구매 영수증 기준, 배송비와 세금 포함)
  - 총 비용: $______

## 6. 소프트웨어 동작

- [ ] PC에서 헤드셋 디스플레이가 확장 화면으로 인식된다
- [ ] Monado 또는 OpenHMD에서 헤드 회전이 가상 카메라 회전에 반영된다
- [ ] 영상이 좌우 눈에 올바르게 분리되어 보인다
